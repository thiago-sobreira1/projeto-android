# Projeto Android

Landing page desenvolvida com HTML e CSS, como parte de um curso de desenvolvimento web front-end.

## 🖥️ Sobre o projeto

Projeto criado durante os estudos de HTML5 e CSS3, com foco em estruturação de layout, uso de imagens e organização de estilos em uma landing page.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 🚀 Como executar

1. Clone o repositório:
```bash
git clone https://github.com/thiago-sobreira1/projeto-android.git
```
2. Abra o arquivo `index.html` no navegador.

## 📚 Aprendizados

Este projeto fez parte da minha jornada inicial em desenvolvimento web, praticando a criação de páginas completas com HTML e CSS e consolidando os fundamentos antes de avançar para tecnologias mais complexas.
